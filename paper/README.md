# Paper materials

Complete figures are in [`figures/final/`](figures/final/README.md), numbered `fig1`–`fig8`.
Run `bash paper/figures/build.sh` from the repository root to rebuild chart panels
and Figures 6 and 8. The manifest maps figures to their inputs and plotting code.

`crop_patching/` contains intervention methods and manuscript material.
`../theory/` contains the binary model, equations, data, and figure builders.
