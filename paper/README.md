# Paper materials

`figures/` is the sole canonical empirical figure bundle. Run `bash figures/build.sh` to regenerate panels, Figures 6 and 8, and validate the manifest. Edit existing code and outputs for visual changes. Do not create final_charts, exports, candidate, or dated duplicate bundles.

`crop_patching/` retains accepted intervention manuscript material. `../theory/` contains the sole current binary theory and its independently reproducible figure.

The figure manifest maps stable asset IDs to regenerable panels. Exact manual composites are preserved separately from their data-driven panels. 

Find all eight complete main-paper figures in [`figures/final/`](figures/final/README.md), numbered `fig1`–`fig8`.
