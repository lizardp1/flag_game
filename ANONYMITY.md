# Anonymous review snapshot

This repository has a fresh history with neutral commit identity. It omits the
website, blog, identifying citation entry, source-machine audit records, unrelated
number-game work, and credentials. PDF/PNG/SVG export metadata has been cleared.
No remote is configured.

Publish only to a separate neutral-account repository or an anonymous review
hosting service. A branch under an identifying account still exposes that account.
Do not copy the original Git history, add identifying author metadata, or link
back to the personal repository when publishing.

Required upstream attribution and scholarly references are retained. Research
content and figures may still be recognizable if they have appeared publicly;
this snapshot removes direct identifiers, not all possible content-based linkage.

Rebuilds can add generator metadata or local paths to generated validation files.
Review those before publishing a later update.
